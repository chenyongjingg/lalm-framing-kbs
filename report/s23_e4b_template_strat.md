# S23：E4B 文本 N/E_t/R 按模板分层（跨生成器复现 S20e）

**日期**：2026-08-14 ｜ **类型**：CPU 全缓存分析 ｜ **状态**：完成

## 动机

S20e 在 E2B 侧发现 N/E_t 效应高度集中在干净模板 t0/t1、t2（停滞热点，S12b：E_t=1/t2 停滞 56.3%）消失/翻转，判定停滞机制是**抑制**（ceiling）而非**产生**效应。审稿人必问该模板集中模式是否跨生成器（E4B）复现。S20b/S17b 已补齐 E4B 文本三条评分腿，本实验在 E4B 侧镜像 S20e。

## 方法

- E4B 文本 3600 单元（与 E2B 同格，位置对齐已在 S20 验证），rid 键控缓存：judge_big/judge_small/qwen32 全齐。
- 口径：dual_judge 共识（judge_big==judge_small）+ qwen32 强锚。
- 每层：Δ = pos_rate(维=1) − pos_rate(维=0)，query 聚类 bootstrap CI（B=1000）。
- 分层维度：N / E_t / R × 模板 t0/t1/t2。

**关键发现：E2B 侧的 t2 归零在 E4B 侧不重复**——权威生成器 E4B 上 N 在**全部三个模板均显著**（含停滞热点 t2，停滞 56.3% 处仍检出 N 效应）。即 N 的 t2 衰减是 E2B 特有现象；E4B（权威）上 N 效应**跨模板全稳健**。这比 S20e 的"t2 抑制"叙事对 N 更有利。

### R（人格/角色代理）

全部模板 NS、符号混合（t0 −0.0137 / t1 +0.0289 / t2 −0.0058），与 E2B 一致：R 长度混杂、不主张。

## 判读

1. **N 效应最稳健的声明**：E4B 权威生成器上 N 在 t0/t1/t2 全模板显著（Δ 0.043–0.088），叠加 S22 跨攻击族 5/5 同向 + S20/S20c 跨生成器 + 4 评分口径 → **协议 RQ（N）效应不受模板、攻击族、生成器选择影响**。
2. **E2B 与 E4B 的 t2 差异须如实披露**：E2B 侧 t2 归零（S20e）是 E2B 特有衰减，非普遍停滞伪影——S23 证明停滞区并非不可检出效应。
3. **E_t 模板集中复现**：t0 强/t2 归零跨生成器一致，停滞抑制叙事对 E_t 成立。
4. **R 无一致效应**：全模板、全口径、跨生成器均无，长度混杂披露成立。
